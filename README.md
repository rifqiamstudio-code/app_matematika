# MATEMATIKA CERIA OS 🌟
> **Belajar Matematika Jadi Seru!**  
> Platform Pembelajaran Matematika Adaptif Berbasis AI untuk Siswa SD Kelas 1–6 (Kurikulum Nasional Indonesia).

---

## 🚀 Fitur Unggulan

- 📚 **Curriculum Engine Berjenjang:** Meliputi Kelas 1 hingga Kelas 6 dengan pohon prasyarat (prerequisite tree).
- 🧠 **Analisis Pola Kesalahan (Mistake Analysis Engine):** Mengetahui mengapa anak salah berhitung (bukan sekadar wrong/true).
- 🎯 **Rekomendasi Adaptif:** Menentukan *"Next Best Activity"* yang tepat sasaran (Remediasi, Latihan, atau Pengayaan).
- 🤖 **Kak Matematika (AI Socratic Coach):** Membimbing proses berpikir visual tanpa langsung membocorkan jawaban.
- 🎮 **10 Mini Games Edukasi:** Balloon Math, Pizza Pecahan, Roket Angkasa, Jam Analog, Kasir Cilik, dll.
- 👨‍👩‍👧 **Parent Insight Portal:** Menyajikan laporan perkembangan pemahaman anak yang mudah dipahami orang tua.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router, React 19, TypeScript)
- **Styling:** Tailwind CSS, Framer Motion, Lucide Icons, Canvas Confetti
- **State Management:** Zustand (Offline-first LocalStorage)
- **Testing:** Vitest

---

## 📦 Menjalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/rifqiamstudio-code/app_matematika.git
cd app_matematika

# Install dependencies
npm install

# Jalankan development server
npm run dev

# Jalankan pengujian otomatis
npm test

# Build production
npm run build
```
